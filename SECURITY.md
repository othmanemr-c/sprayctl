# Politique de sécurité

## Signaler une vulnérabilité

Si tu découvres une faille de sécurité dans `sprayctl` lui-même (pas dans
les systèmes que l'outil cible, mais dans l'outil : injection, gestion de
credentials, etc.), merci de **ne pas ouvrir d'issue publique**.

Contacte plutôt directement [ton email / GitHub Security Advisories] avec :
- Une description du problème
- Les étapes pour le reproduire
- L'impact potentiel

Réponse visée sous 7 jours.

## Périmètre

`sprayctl` est un outil offensif destiné à des tests d'intrusion autorisés.
Le "usage abusif" de l'outil dans son cadre prévu (spray non autorisé contre
un tiers) n'entre pas dans le périmètre de cette politique — voir
[LICENSE](LICENSE) pour l'avertissement d'usage.
